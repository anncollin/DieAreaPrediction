About the Project

OSSDA is built on a dataset that we collected ourselves through chemical decapping and silicon die exposure of 639 integrated circuits across 25 ICT devices. For each IC, we measured the silicon die area and linked it to package characteristics such as package area, package type, pin count, and mass.

Using a classical machine learning workflow with a train/test split and 15-fold cross-validation, we compared six regression architectures: linear regression, group-wise linear regression, support vector regression, multi-layer perceptron, k-nearest neighbors, and decision trees.

The recommended model is a log–log group-wise linear regression depending on package area and package type. In logarithmic space, it fits:

log10(ÂDie) = β · log10(APack) + α

where: ÂDie is the predicted silicon die area (in mm²), APack is the measured package area (in mm²), and the coefficients α and β depend on the package type.

In the original domain, this corresponds to:

ÂDie = a · APackβ,   with   a = 10α

Compared to fixed die-to-package conversion factors, this model reduces the typical multiplicative prediction error from about 3× to 1.9× while maintaining interpretability and reducing systematic bias across IC sizes.

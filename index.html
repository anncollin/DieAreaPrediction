OICDB — Modeling Integrated Circuits

Augustin Wattiez, Anne-Sophie Collin, Robin Dethienne, Tomasz Rola, Marina Proske, and David Bol

We introduce OICDB, an open dataset for integrated circuit modeling dedicated to life cycle analysis. Explore OICDB and use our model to predict the die area of a new device.

Paper Code Dataset

About the Project

OICDB provides an open dataset and baseline models for integrated circuit die area estimation. The database combines multiple circuit parameters to facilitate regression-based and machine learning modeling.

Make Your Own Prediction

Enter the package area and type to predict the die area using our group-wise linear model.
